# План перехода на поддержку страниц памяти 16 КБ

## Описание задачи
Начиная с Android 15 (API 35), устройства могут использовать страницы памяти размером 16 КБ (вместо 4 КБ). Для того чтобы приложение корректно работало на новых устройствах и соответствовало требованиям Google Play (обязательно с 1 ноября 2025 года, а для новых релизов с targetSdk 35 и ранее), необходимо обеспечить поддержку 16 КБ страниц. 
Приложения, написанные исключительно на Java/Kotlin, поддерживают 16 КБ по умолчанию. Однако, если используются нативные библиотеки (`.so`), то требуется их правильное выравнивание. В проекте используются SDK (например, Appodeal, Yandex Mobile Ads), которые содержат нативный код, поэтому необходимо выполнить ряд шагов.

## Task List (Список задач)

- [x] **1. Проверка наличия нативных библиотек в текущей сборке**
  - Собрать APK и проанализировать через *APK Analyzer* (Build > Analyze APK...).
  - Проверить наличие директории `lib/` и `.so` файлов.
  - Проверить текущее выравнивание ELF-файлов в существующих библиотеках.
  - *Результат:* Найдено 34 `.so` библиотеки. Загружаемые сегменты имеют выравнивание 4 КБ (`align 2**12`), требуется 16 КБ.

- [x] **2. Обновление Android Gradle Plugin (AGP)**
  - Текущая версия AGP в проекте была `7.3.1`, обновлена до `8.5.1`.
  - Обновлен Gradle wrapper до `8.7`, Kotlin plugin до `1.9.24`, а целевая Java-совместимость переведена на Java 17.
  - *Результат:* Сборка прошла успешно, проверка `zipalign -c -v 16` подтвердила автоматическое выравнивание нативных библиотек в APK по границе 16 КБ.

- [x] **3. Обновление сторонних SDK**
  - Обновлен Yandex Mobile Ads до версии `7.10.0` (совместима по API и поддерживает 16 КБ).
  - Проверена работа Appodeal SDK `3.2.0`.
  - *Результат:* Сборка прошла успешно, все нативные `.so` библиотеки SDK выравнены на 16 КБ.

- [ ] **4. Обновление targetSdk**
  - В `app/build.gradle` изменить `targetSdk` с `34` на `35` (Android 15), чтобы приложение соответствовало последним требованиям Google Play и правильно обрабатывалось системой на 16 КБ устройствах.
  - Убедиться, что `compileSdk` также равен `35`.

- [ ] **5. Тестирование на устройствах с поддержкой 16 КБ**
  - Установить Android 15 SDK (API 35).
  - Создать виртуальное устройство в Android Emulator с образом системы, поддерживающим 16 КБ (например, *Google APIs Experimental 16 KB Page Size System Image* в разделе VanillaIceCream).
  - Запустить приложение на эмуляторе.
  - Проверить через `adb shell getconf PAGE_SIZE`, что возвращается значение `16384`.
  - Провести полное регрессионное тестирование (особенно запуск приложения, показ рекламы и другие функции, зависящие от нативного кода), чтобы убедиться в отсутствии падений.
